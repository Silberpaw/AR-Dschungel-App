# AR-App
Mein Bachelorarbeitsprojekt. Eine Androidapp (geschrieben in Kotlin), mit welcher Kinder in AR Tiere suchen und speichern können

ARSelfieActivity
-> Activity, in der das Kind Selfies mit den Tieren machen kann
CollectionActivity
-> Sammlung von Tieren für Kinder
MainActivity
-> startet Ablauf des Tierfindprototyps
QuizActivity
-> startet Quiz und Quizfunktionen
StartActivity
-> Funktionen der Buttons im Startmenu
animal
-> Datenklasse, die alle Infos eines Tieres speichert
animalAdapter
-> händelt Tierlisten
